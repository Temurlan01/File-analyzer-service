# Сервис скачивания и анализа файлов

Django REST Framework сервис для скачивания файлов через внешнее API и анализа их содержимого.

## Установка

1. Создайте виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate  # для Windows
# или
source venv/bin/activate  # для Linux/Mac
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте переменные окружения в файле `.env`:
```env
TARGET_API_BASE=http://your-api-url:8000
TARGET_CANDIDATE_ID=your_candidate_id  # опционально
```

4. Выполните миграции базы данных:
```bash
python manage.py makemigrations
python manage.py migrate
```

5. Запустите сервер:
```bash
python manage.py runserver
```

Сервис будет доступен по адресу `http://127.0.0.1:8000`

## Использование

### Скачивание файлов

1. Откройте главную страницу `http://127.0.0.1:8000`
2. Нажмите кнопку "Скачать данные"
3. Процесс скачивания начнётся автоматически
4. Прогресс отображается в реальном времени:
   - Время старта (по Новосибирску)
   - Количество полученных имён файлов
   - Количество скачанных файлов

### Просмотр файлов и расчёты

1. Файлы отображаются с пагинацией (10 файлов на странице)
2. Выберите файлы:
   - Отдельные файлы через чекбоксы
   - Все файлы на странице
   - Все файлы вообще
3. Нажмите кнопку "Произвести расчёты"
4. Результаты отображаются:
   - Общая статистика по всем выбранным файлам
   - Статистика по каждому файлу отдельно

## API Эндпоинты

- `POST /api/start-download/` - Начать скачивание каталога
- `GET /api/files/` - Список файлов (с пагинацией)
- `POST /api/calculate/` - Рассчитать статистику

## Особенности реализации

- Обработка rate limiting (429, 403 ошибки) с учётом заголовка Retry-After
- Скачивание файлами по 3 за запрос (как требует API)
- Отметка файлов как скачанных через API
- Хранение файлов в SQLite базе данных
- Пагинация на сервере и клиенте
- Выбор файлов: точечно, все на странице, все вообще
- Расчёт статистики по цифрам (0-9) в содержимом файлов
- Отображение времени в часовом поясе Новосибирск (UTC+7)
- Использование .env файлов для конфигурации
